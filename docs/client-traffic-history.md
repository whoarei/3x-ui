# 客户流量统计（基于 3x-ui 3.11.0 的定制功能）

面板侧栏和系统状态页提供“客户流量统计”入口。客户列表的曲线按钮直接打开该客户的历史；移动端入口在客户操作菜单中。

## 查询

- 对象：所有客户，或一个客户；支持按客户名称、备注搜索，保留已删除客户的历史入口。
- 时间：滚动最近 1 / 7 / 30 天，或自定义起止日期、时间。
- 近 1 / 7 天默认按小时显示，近 30 天按面板时区的自然日显示；自定义范围自动选择分钟、小时、天、周或月。
- 显示发送给客户（Xray Down / 客户下载）、从客户接收（Xray Up / 客户上传）和总量。曲线表示各区间的字节量，不是速率或累计计数器。
- 所有客户显示两条合计曲线和客户明细表。点击明细里的客户进入单客户查询。

时间范围采用左闭右开 `[from, to)`，起点向下、终点向上对齐到分钟。数据库保存 UTC 时间，显示和自然日分组采用面板时区，处理夏令时的 23 / 25 小时自然日。

## 采集与存储

复用现有每 5 秒客户流量采集。历史与原有流量在同一事务中入账，按客户内部 ID、来源节点、UTC 分钟合并。Xray 采集任务在写库失败后保留本轮增量和原采样时间，成功重试后才继续采集。

远程节点只记录去重后、已经接受的新用量；初次接入的累计计数不能当作刚发生的流量。同一客户多个入站不会因此重复记账。

新增表通过现有数据库 AutoMigrate 创建：

| 表 | 用途 |
| --- | --- |
| `client_traffic_history_clients` | 历史客户标识和显示名称快照，无级联删除 |
| `client_traffic_history_buckets` | 客户、来源、分钟的上传和下载字节数 |
| `client_traffic_history_polls` | 成功采样分钟及最近采样时间，用于识别缺口 |

分钟明细默认长期保留，不自动删除。没有流量的客户不产生用量行，但成功采样会记录覆盖分钟。查询在数据库中按区间聚合，使用时间索引并限制返回的曲线点数；前端复用现有 uPlot。

月度重置、手动清零、调整额度不会删除历史。删除客户仍可查询；新建同名客户使用不同内部 ID。实时客户资料优先于历史名称快照。

## API

复用面板登录和已有 API 权限，返回统计数据，不返回 UUID、密码或订阅凭据。

- `GET /panel/api/clients/traffic-history/options`：客户选项、面板时区、采集起止时间。
- `GET /panel/api/clients/traffic-history?clientId=0&from=<Unix秒>&to=<Unix秒>`：汇总、曲线和客户明细。`clientId=0` 表示所有客户。

## 数据边界与运维

功能启用前的累计用量不能反推出历史分布。采集中断的分钟标为缺口；成功采样但无流量的分钟记为零。部分采集的小时 / 天仍显示已记录的用量，同时提示存在缺口。

一分钟内部的采样归属到采样发生的分钟，时间精度受约 5 秒采样周期限制。面板崩溃或核心重启时，最后未提交的采样不能保证恢复；不把重启前已有累计计数伪造为本分钟用量。客户端流量不等于服务器网卡流量，后者还包括转发另一侧、SSH、面板和其他服务。

新增数据保存在原面板数据库中，沿用数据库备份流程。本功能属于定制构建，官方 `x-ui update` 会替换程序并覆盖功能；后续升级应在新的上游版本合并这份源码后重新构建。回退程序前备份数据库，保留统计表即可供重新启用后继续查询。
